# 🌿 EcoSystem Simulation Project

A biological ecosystem simulation project developed in **C++**, integrating a graphics library to visualize the interactive behaviors and survival mechanics between different biological entities.

## 📖 About
This project simulates a miniature ecological environment. The core focus is to apply Object-Oriented Programming (OOP) principles—specifically Inheritance and Polymorphism—to manage and render the behaviors of various animal species sharing the same habitat.

## ✨ Key Features
* **Entity System:** Well-structured character classes (e.g., `Wolf`, `Rabbit`) inheriting from common base classes to ensure scalable code.
* **Biological Interactions:** Simulating predatory instincts, survival mechanics, and the natural balance of the ecosystem.
* **Visual Interface:** Utilizing the **SFML** library to render 2D graphics, entity animations, and environmental elements (grass, ground).
* **Audio Integration:** Embedded background music and sound effects for a more immersive experience.

## 🛠️ Tech Stack
* **Core Language:** C++
* **Graphics Library:** SFML (Simple and Fast Multimedia Library)
* **IDE:** Visual Studio (Project file `.sln` included)
